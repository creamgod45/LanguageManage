English

LanguageManager works with compatible IntelliJ-based IDEs running JetBrains Platform 2025.3.5 or later.

Install LanguageManager

  1. Launch your JetBrains IDE.
  2. Go to Settings/Preferences > Plugins > Marketplace.
  3. Search for LanguageManager.
  4. Click Install, then restart the IDE if prompted.
  5. Open LanguageManager from the Tool Window sidebar. If it is not visible, go to View > Tool Windows > LanguageManager.

Create your first scheme

  1. Open the New Scheme dropdown.
  2. Choose Select Files or Select Folders.
  3. Select the JSON, YAML/YML, Laravel PHP, or ResourceBundle Properties files you want to manage.
  4. Review the recognized files, enter a scheme name, and click Create Scheme.

LanguageManager only manages files that you explicitly select. It never adds files to a scheme automatically, and every scheme keeps its files and settings isolated.

Configure the plugin

  • Open Settings/Preferences > Tools > LanguageManager to configure the display language, issue visibility, and defaults for new schemes.
  • Use Scheme Settings in the LanguageManager Tool Window to configure the active scheme's managed files, usage-scan base path, Regex patterns, exclusions, and loading limits.

Complementary and conflicting plugins

LanguageManager is standalone and does not require any complementary plugins. It can be used alongside framework-support and localization plugins. There are currently no known conflicting plugins; however, avoid editing the same localization file simultaneously with multiple tools.

繁體中文

LanguageManager 適用於執行 JetBrains Platform 2025.3.5 或更新版本的相容 IntelliJ 系列 IDE。

安裝 LanguageManager

  1. 啟動 JetBrains IDE。
  2. 前往設定/偏好設定 > Plugins > Marketplace。
  3. 搜尋 LanguageManager。
  4. 按一下安裝，並在 IDE 提示時重新啟動。
  5. 從 Tool Window 側邊欄開啟 LanguageManager。如果沒有顯示，請前往 View > Tool Windows > LanguageManager。

建立第一個方案

  1. 開啟新增方案下拉選單。
  2. 選擇選取檔案或選取資料夾。
  3. 選取要管理的 JSON、YAML/YML、Laravel PHP 或 ResourceBundle Properties 語言檔。
  4. 檢查辨識結果、輸入方案名稱，然後按一下建立方案。

LanguageManager 只會管理您明確選取的檔案，不會自動將任何檔案加入方案。每個方案的檔案與設定皆彼此隔離。

設定插件

  • 前往設定/偏好設定 > 工具 > LanguageManager，設定插件顯示語言、問題顯示選項及新方案預設值。
  • 使用 LanguageManager Tool Window 中的方案設定，調整目前方案的列管檔案、使用率掃描基礎路徑、Regex 規則、排除清單及載入上限。

互補與衝突插件

LanguageManager 可獨立運作，不需要安裝其他互補插件，也能與框架支援及在地化相關插件搭配使用。目前沒有已知的衝突插件；但建議避免同時使用多個工具編輯相同的語言檔。
